# 残差策略实验报告

## 实验设置

MuJoCo / SB3 PPO，CPU，种子20261101，4个并行环境；128×128网络，rollout 256，batch 256，5个优化epoch，学习率0.0001，gamma 0.995，训练窗口512步。两次运行各32,768步，只有残差上限不同。

|控制器|交互预算|最大实际转角|运行时长|全程穿透峰值|末5秒夹持|严格质量|
|---|---:|---:|---:|---:|---|---|
|混合参考，零残差|不适用|365.69°|42.28s|2.676mm|100%|未通过|
|大幅度残差|32,768|106.13°|3.96s|2.252mm|不足5秒，不满足保持验收|未通过|
|小幅度残差|32,768|112.65°|4.02s|3.314mm|不足5秒，不满足保持验收|未通过|

整圈视频证明参考辅助控制在该条件下的动作表现；目前没有可核验的新残差整圈成功报告。两次独立训练累计65,536步，所选小幅度模型为8,192步检查点，不能称为单模型65,536步。
