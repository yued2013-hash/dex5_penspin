# 有界残差PPO与混合专家参考

## 设计动机

耦合关节与多指接触切换使整圈探索困难。参考控制提供可执行动作骨架，PPO学习有界修正；通过零残差对照，检验策略能否改善稳定性而非仅复制演示。

## 混合专家参考轨迹构建

采用 **PPO引导的混合专家参考轨迹**：物理规划前缀与MuJoCo特权PPO收尾相结合。该收尾策略不是Isaac Lab原Oracle网络，不能把这条参考写成Isaac Oracle完整生成。

|区间（左闭右开）|时段|控制来源|
|---|---|---|
|0–1614帧|0–32.28s|物理规划前缀|
|1614–2114帧|32.28–42.28s|PPO收尾，动作EMA系数0.07|

全程50Hz控制、1kHz物理积分，片段切换不重置物理状态。收尾检查点来自61,440步历史训练，滤波未新增训练。保存轨迹、生成器和收尾检查点的SHA-256见[谱系档案](../experiments/rl13/runs/reference_baseline/provenance.json)。生成器及收尾模型尚未随本快照打包，不能由哈希声称已完整提供生成链。

## 控制结构

`r[t] = 0.85*r[t-1] + 0.15*L*pi(obs[t])`

`u[t] = clip(u_ref[t] + r[t], joint_limits)`

残差滤波系数0.15与参考收尾滤波0.07作用于不同模块。16维动作、101维特权观测；观测含模拟笔状态、关节误差、动作历史、参考控制、相位及五指接触力。不能直接部署到缺少笔位姿感知的实机。

## 奖励与验收

奖励包括参考位姿跟踪、双指支撑、势函数差分与动作突变代价。训练窗口从经校验的阶段状态起步，正式评估从真实初态连续执行。整圈行为、终态夹持与全程≤0.5mm穿透分别统计。

具体奖励、终止与状态恢复合同见[实现说明](rl13_method.md)；[实验报告](residual_ppo_experiment.md)给出实际结果。
