# 数据扩展计划：目标与已有成果分开

## 现有基线

项目报告包含1200个验证episode、69,600个Student transition，按来源划分891/112/197个训练/验证/测试episode。当前Student测试197个episode来自20个来源。本轮只整理工程与文档，未采集新增Isaac轨迹、重训Student或产生新的实机数据。

## 执行前置条件

1. 恢复报告对应的有效原始数据和检查点，确认并排除Git LFS指针；核验SHA-256与数据版本。
2. 对齐姿态差分角速度、终态预重置记录、关节顺序、单位和控制时序。
3. 冻结已有训练/验证/测试来源；新采集不修改旧记录。新状态按原工程R0–R3合同验证后才能晋级使用。
4. 在原GPU/Isaac环境执行采集；MuJoCo渲染不生成新的Isaac动力学样本。

|阶段|采集目标|验收重点|
|---|---|---|
|小批增量|先新增200个候选episode|姿态、接触、穿透和保持联合验收，报告拒绝数与失败原因|

各目标不保证成功采集数，实际transition数由合格episode长度决定。若增加摩擦、质量或延迟随机化，必须单独记录条件并重复适用的验证；本计划不自动解冻旧分支或授权实机带电回放。

## 最低报告字段

候选数、合格数、拒绝原因、独立来源数、每种条件数量、transition总数、数据hash、训练/验证/测试来源分组，以及同一任务下的基线/新模型结果。复制轨迹、重复渲染和插值增加的帧数不计为独立来源或新增真实采集。
