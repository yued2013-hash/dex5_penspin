# 数据规模与实验统计

## Student离线数据集

共有 **1,200条验证轨迹、69,600个状态转移样本**。样本包含340维可部署观测历史、20维有界动作及相应下一观测、终止标签与来源元数据。数据划分按 `source_trajectory_id` 隔离。

|划分|Episode数量|状态转移样本|
|---|---:|---:|
|训练|891|51,621|
|验证|112|6,519|
|测试|197|11,460|
|合计|1,200|69,600|

数据集总量包含验证与测试样本；实际BC训练使用51,621个训练样本。重复训练epoch、观测历史窗口和同一来源的重复回放不增加独立样本或来源数量。100-episode过拟合检查是子集验证，不额外计入总量。

来源：[Student训练报告](../Dex5_Sim2Real_S0/student_s0_11/student_training_report.json)。历史数据集SHA-256：`04fdd611ba255715d5d4159a1e7d933ee1c77d58871d00bcdc9e26d61db7e746`。

## 闭环评估覆盖

197个测试episode来自20个独立测试来源。Student取得152次严格短角度成功、184次至少30°实际姿态转动。这里的独立性指来源划分，不代表197种独立对象或全新操作条件；当前覆盖仍有限。

来源：[闭环评估](../Dex5_Sim2Real_S0/student_s0_11/student_closed_loop_eval.json)。

## MuJoCo残差PPO控制实验

|运行|实际训练交互步数|所选检查点步数|结果|
|---|---:|---:|---|
|大残差上限0.006 rad|32,768|32,768|未完成全程|
|小残差上限0.00006 rad|32,768|8,192|未完成全程|
|两次独立运行合计|65,536|—|均未晋级|

这是两次独立实验的环境交互预算，不是单模型训练时长，也不是新增65,536个验证成功样本。实验只有一条参考来源，不支持泛化成功率结论。不能将此处步数与Student数据集相加为一个训练集。

来源：[大残差报告](../experiments/rl13/results/training_report.json)、[小残差报告](../experiments/rl13/results/micro_training_report.json)。
