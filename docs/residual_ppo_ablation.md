# 残差幅度消融

在相同参考、起点、种子、网络、奖励与训练预算下，对比两种有界残差幅度。

| 条件 | 残差上限 | 训练预算 | 最大转角 | 执行时长 |
| --- | ---: | ---: | ---: | ---: |
| 大幅度 | 0.006 rad | 32,768 | 106.13° | 3.96s |
| 小幅度 | 0.00006 rad | 32,768 | 112.65° | 4.02s |

缩小残差上限后，所选检查点最大转角增加6.52°，执行时长增加0.06s。对照结果与零残差参考统一记录在[实验报告](residual_ppo_experiment.md)中。

## 对照设计

- 以零残差参考为基准，逐项记录实际转角、保持、接触与穿透。
- 使用固定初态与训练预算，每8192步进行全流程检查点评估。
- 保存所选模型、最终模型、训练日志、评估报告和SHA-256索引。
