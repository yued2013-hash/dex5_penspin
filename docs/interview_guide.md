# 面试展示提纲

## 90秒开场

“这个项目研究耦合关节Dex5手上的笔状物体灵巧操作。我把工作分成建模与控制、学习与数据、评估与复现三部分。现有整圈仿真基准能完成约365.7°转动并稳定夹持，但依赖物理参考，还有局部穿透；我没有把它说成端到端RL已经解决。

为了优化全流程，我新增相位条件残差PPO：101维状态、16维动作，在整段控制中修正参考目标。两次相同预算训练共65,536步，比较不同残差幅度，目前都未超过基准。因此工程上保留稳定基准，研究上保留失败证据，下一步优先修正接触几何与支撑鲁棒性，而不是盲目加大训练规模。”

## 5分钟演示顺序

1. 打开展示页，播放整圈基准，跳到拇指退让、接回和稳定夹持阶段。
2. 解释 `u = u_ref + residual`，明确参考辅助和privileged观测。
3. 切换“本轮全流程RL”，展示实际训练预算与失败候选；解释幅度消融为何值得做。
4. 展示姿态转角、接触持续时间和穿透门槛，说明如何避免“假转动”和指标投机。
5. 指向训练/评估入口、日志、来源hash与测试，最后讲可验证的下一步。

## 可以重点讲的工程贡献

- 实现恢复状态验证、接触消抖、末段保持验收与独立几何质量审计。

这些是工程设计与实验贡献；PPO、残差学习、Oracle→Student均有公开来源，不宣称算法首创。

## 常见追问

**是不是纯RL学会整圈？** 不是。目前整圈依赖参考动作；本轮RL在全程输出修正，但候选未超过基准。

**为什么不直接多训练？** 同预算缩小残差100倍也未解决完整执行。当前只有一个脆弱参考来源，并存在几何穿透，首先需要排查接触模型和局部可控性。

**怎么证明转了？** 看连续笔姿态方向的有符号展开角，并结合投影质量与四元数差分；不只看瞬时角速度积分。

**152/197与整圈有什么关系？** 它是原项目历史Isaac短角度学生策略的独立任务结果，不是整圈成功率。

**能上实机吗？** 新残差策略依赖模拟笔状态，未进行本轮学生蒸馏或实机验证。原工程实机接口与标定独立保留，不能直接把MuJoCo控制映射到硬件。

**如何划分训练测试？** 当前新实验只有1个来源，不宣称独立泛化。历史学生评估按来源隔离，报告197个episode来自20个unique source，而不是197个独立来源。

**项目最有价值的发现？** 能转、能夹住与物理质量合格是不同门槛；稳定参考下微小残差也可能破坏混合接触过程，算法比较必须包含完整连续回放与失败诊断。
