# Dex5实机迁移与工程诊断

项目将Isaac Lab Oracle训练和Student蒸馏与Dex5控制接口衔接，完成关节映射、局部响应辨识、静态持笔、受控轨迹回放及局部可见转动验证。

## 已实现的适配与诊断

| 环节 | 实际记录 | 工程处理 |
| --- | --- | --- |
| 关节耦合 | 20维URDF目标、16个独立通道；局部PIP/DIP响应比约0.29 | 在适配层保留耦合约束与厂商URDF到电机转换 |
| 方向、偏置与迟滞 | 16/16通道方向映射；全范围往返扫描 | 分方向分段逆映射与局部修正，保存原始反馈 |
| 控制时序 | 策略60Hz、指令链100Hz；可检测起动延迟14–31ms | 动作保持、指令插值与时延记录 |
| 增益与负载 | 负载回放反馈瞬态、低增益持笔记录 | 预加载、慢速姿态对齐、稳定窗口检查与逐段回放 |
| 物体与接触 | 约9.8mm直径笔下静态持笔和2秒前缀回放 | 统一笔尺寸及接触条件，记录持笔与局部转动 |
| 反馈与测量 | 原始SDK速度与位置差分速度 | 50ms位置差分作为执行反馈，原始速度保留作诊断 |

## 从标定到持笔回放

先完成空手映射与方向检查，再执行负载静态保持和有限时长前缀回放。9.8mm笔条件下的2秒前缀记录为201/201行完成，笔保持在手中并观察到局部转动，50ms位置差分速度峰值0.00143 rad/s。

每轮回放保留控制目标、位置反馈、时序、运行条件及操作者观察。适配器包含速度、指令增量、看门狗、热监控与停止处理；实际硬件操作按[阶段记录](../AGENTS.md)中的对应流程执行。
