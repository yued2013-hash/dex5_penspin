- 开发MuJoCo轨迹回放与动作可视化工具，结合四元数姿态、接触切换及稳定保持指标分析转动和接回过程，支持仿真策略与实机迁移问题诊断。

## 面试追问时的准确解释

**Isaac训练、MuJoCo可视化是怎么衔接的？** 仓库有将Isaac记录的关节和笔位姿映射到MuJoCo模型做回放渲染的工具。状态可视化与策略在MuJoCo重新闭环运行是不同任务，后者还需要模型、观测、动作和时序适配。本次整理未新增跨引擎闭环认证。

**当前整圈视频就是Student输出吗？** 当前展示的整圈视频来自项目诊断模块，采用规划辅助和PPO收尾；它与Isaac Student短角度评估不是同一项实验，不能把两者合成整圈策略成功率。

**77.2%怎么计算？** 历史Student报告中152/197个episode满足严格短角度任务门槛，测试episode来自20个来源；不是197个独立来源、实机成功率或整圈成功率。

**实机问题是否就是Dex5设置？** 已有耦合、增益、负载反馈瞬态和控制时序的记录，支持这些排查方向，但尚未完成单一原因的因果消融。

**数据量还能扩大吗？** 可以通过新采集和验证扩展，目标与实测统计分开。当前简历只写已有1200条轨迹和69,600条transition，不将重复回放或插值帧当成独立新轨迹。
