# RL13 方法、奖励与实验合同

本支线于2026-11-01根据用户“采用强化学习思路优化整体流程并整合展示”的新请求建立，授权范围是独立仿真实验与项目展示整理。它不解冻旧O0/S0训练分支，不连接硬件，不改变历史标定、原始数据和真机安全门槛。

## 为什么采用残差学习

Dex5耦合关节和接触切换使从零探索整圈动作困难。把已有参考动作作为基础控制，学习小幅修正，可以直接检验“有了可执行参考后，RL能否改善全流程”。这是[Residual Reinforcement Learning](https://arxiv.org/abs/1812.03201)的常见思路，不是本项目首创。优化器使用[SB3 PPO](https://stable-baselines3.readthedocs.io/en/master/modules/ppo.html)。

本项目借鉴[Lessons from Learning to Spin “Pens”](https://arxiv.org/abs/2407.18902)的仿真学习和分阶段验证思路，但本轮没有实现论文中的实机数据微调或多物体多圈效果。

## 控制与观测

`u_t = clip(u_ref[t] + r_t, joint_limits)`；`r_t = 0.85 r_(t-1) + 0.15 * limit * action_t`。基础控制频率50Hz，MuJoCo物理步长1ms；16个主动控制通道、4个约0.829比例的远端耦合关节。该比例是新支线的仿真假设，与旧工程约0.29的局部硬件辨识不是同一模型，不能混用。

101维观测构成为：关节位置误差16、关节速度16、笔位置误差3、笔四元数对数误差3、笔线/角速度6、参考控制16、滤波残差16、上一动作16、相位特征4、五指接触力5。具体归一化见 `experiments/rl13/env.py`。

策略用模拟笔状态，属于privileged/oracle层；没有蒸馏成本轮新增的可部署学生。

## 奖励

奖励包含参考笔位置和姿态的指数跟踪奖励、至少两指支撑奖励、潜势差分、动作和控制突变代价。潜势为笔位姿误差的截断负二次项，使用 `gamma * Phi(next) - Phi(current)`。物理失败时增加剩余窗口长度相关的惩罚，降低提前失败逃避负奖励的动机。这个设计需要用实际return-order审计检验，不能仅由公式宣称消除了所有奖励投机。

终止条件包含笔高度过低、相对参考漂移超过7cm、掌心接触、非有限状态或仿真警告。完整评估还检查实际转角、末5秒夹持、穿透和最长无支撑间隔。速度与转角的有限步证据来自笔姿态差分；瞬时速度另列为诊断。

## 数据与模型选择

仅一个确定性参考来源，完整状态中包含控制目标与积分上下文。先校验阶段起点，再训练短窗口，最后评估从真实起点运行的全流程。没有随机切分同一轨迹的相邻帧来宣称独立测试；当前独立测试来源数量为0。

两次幅度消融使用同一参考、起点、种子、网络、奖励和预算，只改变最大残差幅度。每8192步记录完整评估，保存所选模型与最后模型。新的“严格质量”字段独立于早期训练时的行为选择分数，新增候选未晋级。

## 后续优化的优先级

1. 排查基准全程2.68mm接触穿透峰值，修正几何与接触参数后重新认证参考。
2. 在预先固定的扰动集合上比较零残差与学习残差；先证明局部可控性与支撑裕量，避免直接扩大训练步数。
3. 增加独立成功参考来源并按source分组评估，再讨论多技能或多物体泛化。
4. 只有仿真质量与源隔离验证通过后，才考虑学生蒸馏和独立的实机阶段。
